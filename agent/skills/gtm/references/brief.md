# GTM brief checklist

Capture only what changes the work. Ask for what is missing; never fill it in.

1. **Offer** — what is delivered, the outcome, who buys, who uses.
2. **Proof** — real customers, results, or credentials the user can state.
3. **Market** — target segment, size of company, trigger events, exclusions.
4. **Commercials** — price model, range, terms, constraints (user decides).
5. **Channel** — email, intros, events, inbound, existing network.
6. **Capacity** — how many conversations per week the user can actually run.
7. **Pipeline home** — Tempo (company pipeline) or a Sheet (project tracker).

## Stage routing

| Signal | Skill | Output |
| --- | --- | --- |
| "What am I selling", vague or new offer | `offer-discovery` | offer brief |
| Segments, ICP, positioning, competitors | `market-positioning` | positioning doc |
| Lead or prospect list from an ICP | `lead-generation` | scored list |
| One company in depth | `company-research` | research note |
| Price, packaging, proposal terms | `pricing-and-terms` | pricing options |
| Cold email, follow-ups, sequences, replies | `outreach-and-messaging` | drafts, tracker |
| Conference, meetup, meeting prep or follow-up | `events-and-meetings` | brief, follow-ups |
