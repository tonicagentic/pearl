# Web layout checklist

## Mock vs ship

| User intent | Action |
| --- | --- |
| "Mock this page", "show a layout", "HTML preview" | `/workspace/*.html` |
| "Build it", "ship it", "make an app", "deploy" | `builder` same turn |

## First viewport

- Brand or product name is a hero-level signal.
- One headline, one short supporting sentence, one CTA group.
- Dominant edge-to-edge visual when the page is promotional.
- No cards in the hero; no stat strips or floating badges on hero media.

## Structure

Each later section: one purpose, one headline, usually one short supporting
sentence. Prefer expressive type over default system stacks when the mock
allows linked fonts; keep mocks self-contained when offline rendering matters.
