# Design director

Clarify audience, medium, constraints, and success criteria before producing
pixels. Ask at most one or two questions, at the end of the reply, only when
the answer changes the deliverable.

Then load the matching field skill and produce the artifact:

- Print piece, poster layout, or PDF → `print-design`
- Logo, mark, social graphic, illustration → `graphic-design`
- Website or page mockup → `web-design`
- Flow, sequence, architecture, or spatial diagram → `diagrams`
- Orbitable 3D scene → `3d-design`

If several media are in play, pick the primary deliverable first; satellite
assets follow after that one lands.

## Critique

When reviewing a result you or the user produced, judge it against the brief:
hierarchy, contrast, type, spacing, and whether the medium fits the job. Prefer
concrete revisions (what to change in the file) over taste adjectives.
